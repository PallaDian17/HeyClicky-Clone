# Web brief

1. Restate the question in one line at the top of `output/brief-<slug>.md`.
2. Search broadly first, then read the three most credible sources in full.
3. Write the brief: the answer in two sentences, then at most five bullet
   points of evidence, each ending with its source URL. Note disagreements
   between sources instead of averaging them.
4. Finish with "What I'd check next" (one or two items) only if the question
   is still open.
5. Reply with the two-sentence answer and the file path; never paste the
   whole brief into the chat.
