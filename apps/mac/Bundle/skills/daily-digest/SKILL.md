# Daily digest

- Compare today with your dated note from the previous run (keep it in
  `tmp/digest-state.md`); report only what is new or changed.
- Sources, in order: files in `output/` and `tmp/attachments/`, then any
  connected integrations (mcp__ tools) for unread or recent items.
- Write at most eight bullets, most important first, to
  `output/digest-<date>.md`, and reply with the top three. If nothing
  changed, reply exactly: Nothing new.
